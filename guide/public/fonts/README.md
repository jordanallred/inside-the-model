Web fonts are served locally under the accompanying SIL Open Font Licenses.

- Inter: Google Fonts `ofl/inter/Inter[opsz,wght].ttf`, optical size 14, weights 400–600.
- JetBrains Mono: Google Fonts `ofl/jetbrainsmono/JetBrainsMono[wght].ttf`, weights 400–600.
- Source Serif 4: the existing `source-serif-4-medium.ttf`, weight 500. The TTF remains available for the brand asset generator.

The WOFF2 files are Latin subsets produced with fontTools 4.67.0. They include Latin-1, common punctuation, combining marks, arrows and the minus sign. Other characters use the existing system fallback fonts. No font is loaded from a third-party stylesheet.
