# Inside the Model — Brand Guide v1.0

**Brand promise:** Make the invisible inspectable.  
**Tagline:** From text to tensors to understanding.  
**Hero:** See exactly how LLMs work.  
**Supporting copy:** An interactive guide to the calculations, code, training, and inference behind large language models.

## Identity
Layered translucent planes represent stages of processing; a connected line and nodes represent inspectable data flow. This is a metaphor, not a literal transformer schematic. The identity is precise, approachable, and quietly technical, never mystical or hype-driven.

## Color
- Deep Space `#0B1020`: dark background and headings
- Indigo `#6366F1`: primary identity and CTAs
- Sky `#3B82F6`: input and interactions
- Teal `#14B8A6`: data flow and completion
- Violet `#A78BFA`: intermediate activations and attention
- Peach `#FB923C`: generated outputs
- Sand `#F8FAFC`: light reading background
- Slate `#334155`: secondary text

Color encodes meaning, not decoration. Check WCAG contrast; avoid small white text on light accent colors. Provide non-color distinctions in diagrams.

## Typography
Plus Jakarta Sans 700–800 for display/headings; Inter 400–600 for body and UI; JetBrains Mono for code, shapes and tensor values; KaTeX for mathematical notation. Use tabular numerals for matrix values.

## Voice
Clear, exact, explanatory and curious. State assumptions and simplifications. Prefer “Inspect the actual attention scores” to “Unlock the secrets of AI.” Distinguish exact computational traces from open questions about model interpretability.

## Graphic grammar
Use grids, labeled matrices, token pills, directed lines, layered planes, and incremental reveal. Avoid stock robots, brains, glowing AI heads, or ornamental circuits. Actual data and conceptual diagrams must be clearly distinguished.

## Logo rules
Use the horizontal logo on wide surfaces and stacked on narrow placements. `symbol.svg` is transparent; `favicon.svg` has a dark rounded background. Keep clear space at least one small node diameter around the mark. Symbol minimum 24px, simplified favicon at 16px, full lockup minimum 180px. Do not rotate, distort, recolor layers, or place over busy photography. Logos contain live text and should be converted to paths for print handoff.

## Site design
Light is the default long-form reading mode; the dark theme suits the Explorer and hero. Article max width 760px; Explorer max width 1200px; use an 8px spacing scale. On larger screens align visual, math and code panes; stack on mobile. Include keyboard navigation, reduced-motion alternatives, numeric value access, copyable examples, and accessible diagrams.

## Applications
Homepage, lesson cards, Explorer, GitHub README, favicon, course completion certificate, 1200x630 social card, 1080x1080 educational visual, slides and apparel. Prefer monochrome symbol for restricted print jobs.

These are starting vector assets and design tokens; trademark and domain availability have not been cleared.
